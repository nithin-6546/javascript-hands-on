# JavaScript Hands-On Repository

Welcome to the `javascript-hands-on` repository! This project contains a collection of JavaScript assignments, exercises, and mini-projects organized week by week. It serves as a comprehensive resource for learning and practicing JavaScript, ranging from fundamental concepts to advanced backend integrations.

## Repository Structure

- **[WEEK-1](./WEEK-1/README.md)**: Introduction to JavaScript basics, including arrays, objects, control structures, and operators.
- **[WEEK-2](./WEEK-2/README.md)**: Intermediate concepts like classes, date operations, deep/shallow copying, and mini-projects like E-Commerce and Todo Apps.
- **[WEEK-3](./WEEK-3/README.md)**: Backend integration using Node.js and MongoDB operations.

## How to Use

Navigate to each week's folder to find specific scripts and projects. Each folder contains its own `README.md` file detailing the files and concepts covered within that section.

To run the JavaScript files, make sure you have [Node.js](https://nodejs.org/) installed, and execute them via the terminal:

```bash
node filename.js
```
