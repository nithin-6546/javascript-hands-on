# Master Collections

This folder focuses on advanced use cases for JavaScript collections, specifically `Map` and `Set`, utilizing them to build various data management engines.

## Files Overview

- **`course-catalog-engine.js`**: A script to manage course offerings, likely using maps or sets for quick lookups and uniqueness.
- **`role-engine.js`**: Manages user roles and permissions.
- **`shopping-cart engine.js`**: An alternative approach to managing a shopping cart using advanced collections.
- **`users-processing-engine.js`**: Handles operations on a collection of users (e.g., filtering, grouping).

## How to Run

Run any of the engine scripts directly:

```bash
node course-catalog-engine.js
```
