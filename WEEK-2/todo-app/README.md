# Todo App Mini-Project

A simple modular Todo Application demonstrating state management, data validation, and modular JavaScript code structure.

## Files Overview

- **`main.js`**: The primary script that initializes the application and handles core logic.
- **`task.js`**: Defines the task object structure and related operations.
- **`validator.js`**: Contains utility functions to validate user input (e.g., ensuring task names are not empty).

## How to Run

Execute the main script to see the logic in action:

```bash
node main.js
```
