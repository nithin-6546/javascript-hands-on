# E-Commerce Mini-Project

This folder contains a mini-project that simulates the core logic of an E-commerce application using Object-Oriented JavaScript.

## Files Overview

- **`app.js`**: The main entry point that ties the application logic together.
- **`cart.js`**: Logic for managing a user's shopping cart (adding/removing items).
- **`discount.js`**: Handles the application of discount codes or sales logic.
- **`payment.js`**: Simulates the payment processing flow.
- **`product.js`**: Defines the product structure and inventory logic.

## How to Run

Execute the main application script:

```bash
node app.js
```
