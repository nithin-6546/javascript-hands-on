# Backend + MongoDB

This project demonstrates the core integration between a Node.js Express server and a MongoDB database using Mongoose.

## Folder Structure

- **`API/`**: Contains the REST API endpoints and business logic.
- **`model/`**: Contains the Mongoose schemas and models.
- **`server.js`**: The main server file that establishes the database connection and mounts the APIs.
- **`request.http`**: A file containing HTTP requests to test the API directly from your IDE.

## Setup Instructions

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Start the server:**
   ```bash
   npm start
   # or
   node server.js
   ```
