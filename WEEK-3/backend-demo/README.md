# Backend Demo (Express Server)

This directory serves as a basic introduction to setting up an Express server in Node.js without the complexity of a database.

## Folder Structure

- **`APIs/`**: Contains basic API route handlers.
- **`server.js`**: The main server initialization file.
- **`request.http`**: A file containing HTTP requests to test the basic API routes.

## Setup Instructions

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Start the server:**
   ```bash
   npm start
   # or
   node server.js
   ```
